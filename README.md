# WRF Tools

Collection of Python scripts for reading, processing, analyzing, and visualizing
Weather Research and Forecasting (WRF) model output.

## Scripts

### wrfout_read.py
Reads and processes WRF output (`wrfout`) files and extracts meteorological
variables for analysis and post-processing.

### Temp_Stat.py
Performs statistical analysis and comparison of temperature data from WRF
simulations and observational/reference datasets.
